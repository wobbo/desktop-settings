# Desktop Settings

*A personal hobby project for GNOME.*

I like GNOME, but there were a few things I missed. Some settings were spread across GNOME Settings, different extensions and other tools, and some things took more effort than I wanted.

So I started making **Desktop Settings** for my own desktop. The idea is simple: keep the things I use in one place, add the options I was missing, and let GNOME stay GNOME.

## What can you change?

- **Wallpapers:** create and edit your own backgrounds, with separate images or colours for light and dark mode, plus options for how they fit the screen.
- **Dock:** adjust its position, size, visibility, scrolling and behaviour.
- **Desktop icons:** choose what appears on the desktop and how icons are arranged.
- **Windows:** tweak window behaviour and screen-edge tiling.
- **Startup applications:** manage what starts when you log in.
- **GNOME extensions:** access related extension options without hunting through several settings windows.

## A little note

This is **my personal hobby project**, not an official GNOME application. I originally made it for my own GNOME setup on Debian and Raspberry Pi OS, and I'm still improving it as I use it.

I'm sharing it in case someone else misses the same little things in GNOME.
